# 理论依据与归因说明

本项目从行为科学视角组织短视频观察，具体借鉴行为经济学、认知心理学与传播研究。六类用户行为与视觉、文案检查项由项目按策划和交付需要组织，并非某一篇论文提出的统一“爆款模型”，也尚未完成抖音真实样本上的预测校准。

## 理论怎样进入分析

使用路径为：**观察具体画面或台词 → 提出候选机制 → 指向可能影响的行为 → 说明验证所需数据 → 判断当前产品是否适用**。

例如，参考视频开头提出一个具体问题，后面逐步交付答案，可以用“信息缺口”组织观察，提出其可能提供继续观看理由的假设。是否真的提高留存，需要比较实际留存数据；仅看视频不能确认观众产生了什么心理。

| 研究线索 | 文献讨论的内容 | 本项目的应用提案与边界 |
|---|---|---|
| 信息缺口与好奇心，认知与决策心理研究 | Loewenstein（1994）综述好奇心研究，并提出以知识缺口理解好奇心的理论。[论文，作者大学主页](https://www.andrew.cmu.edu/user/gl20/GeorgeLoewenstein/Papers_files/pdf/PsychofCuriosity.pdf) | 检查开头提出什么问题、答案如何释放；将继续观看视为待验证假设，不把悬念直接等同于留存提升 |
| 前景理论、损失与收益框架，行为经济学 | Kahneman 与 Tversky（1979）提出风险决策的前景理论；Tversky 与 Kahneman（1981）研究同一决策问题不同表述下的偏好变化。[前景理论，作者大学主页](https://kahneman.scholar.princeton.edu/sites/g/files/toruqf3831/files/kahneman/files/prospect_theory.pdf)、[框架研究，Science](https://doi.org/10.1126/science.7455683) | 观察内容强调获得什么或避免什么损失，作为脚本比较变量；原研究情境不等于短视频收藏或购买，不能据此套固定效果倍数 |
| 自我关联与记忆，认知心理学 | Rogers、Kuiper 与 Kirker（1977）在词语编码与回忆实验中发现自我关联编码的优势。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/909043/) | 检查人群、场景与问题是否具体相关；把对观看或记忆的影响列为待验证，不直接宣称身份标签必然阻止划走 |
| 加工流畅性与审美反应，认知与社会心理研究 | Reber、Schwarz 与 Winkielman（2004）综述加工流畅性与审美愉悦的关系。[论文，期刊页面](https://journals.sagepub.com/doi/10.1207/s15327957pspr0804_3) | 观察画面、文字层级与信息呈现是否便于加工；这是项目的应用外推，不能从清晰程度直接推算点赞、转化或内容质量 |
| 情绪与社会传播，营销传播研究 | Berger 与 Milkman（2012）结合《纽约时报》内容数据及实验研究情绪与分享传播的关系。[论文，期刊页面](https://journals.sagepub.com/doi/10.1509/jmr.10.0353) | 为分析情绪线索、实用信息与分享理由提供参考；迁移到抖音需要重新验证，不能将其当作平台推荐算法或本视频传播效果的证明 |

上表是代表性理论线索及其出处，不是整个 Skill 中每条经验规则的逐条验证。将这些概念用于视频拆解属于项目的应用提案，具体判断仍需素材证据、人工复核和后续数据检验。

## “归因”在哪一步成立

| 层次 | 当前能提供什么 | 判断所需条件 |
|---|---|---|
| 内容机制分析 | 指出具体元素、可能影响的行为、可迁移条件和未知项 | 本地素材、字幕或已有分析；表现未提供时不确认“为什么爆” |
| 比较设计 | 按预算提出直出、单变量 A/B 或交叉矩阵，记录方向、技巧、开场与执行差异 | 足够的可用条数、负责人确认的方向及明确的比较问题；条数档位不等于统计功效 |
| 效果归因与验证 | 提供记录与复盘指南，量化效果验证记录待补充 | 明确结果指标、可比的对照或可靠识别设计、实际数据与合适分析，并处理达人、发布时间、投放条件和执行偏差等因素 |

一条热门视频的表现可能同时受到创作者、受众、投放、发布时间和内容等因素影响。仅从成片提炼机制，无法分配这些因素的因果贡献；已经热门的样本也不能代表未热门样本。平衡矩阵的描述性差异不直接写成“显著”或“已归因”。预算规则和比较说明见[Brief Skill](../skills/sherry-brief/SKILL.md)。

## 不同业务目的怎样使用框架

- **曝光与认知：**内容侧关注留人、理解与传播线索；曝光和覆盖需实际分发数据，认知效果另行测量。内容分数不能替代这两类结果。
- **种草：**先把目标人群、使用场景与产品价值写清，再选择合适的意向或行为验证；收藏、评论和商品访问各有不同含义，不能直接当作成交。
- **互动与传播：**先约定要观察的具体行为、统计分母与窗口，再设计内容变量并比较结果。

当前 Skill 支持围绕这些目的组织分析和拍摄方案；真实投放效果的系统测量见[后续验证计划](portfolio-overview.md)。独立的[行为机制拆解](../skills/sherry-douyin-behav/SKILL.md)提出解释假设，[八维诊断](../skills/sherry-douyin-review/SKILL.md)提供内容设计判断，[执行验收](../skills/sherry-douyin-shenhe/SKILL.md)核对已确认 Brief 的要求，三者分别记录。
