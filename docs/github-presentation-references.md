查看日期：2026-11-27。以下只比较公开 README 的信息组织，不把项目自述当作效果验证，也未复制代码、图片或原文模板。

| 参考项目 | 可借鉴的展示方式 | 在本作品中的应用 |
|---|---|---|
| [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) | 开头点明用户与任务；用关系图和能力表解释模块怎样配合 | 首页先解释内容协作场景，再给流程与能力入口 |
