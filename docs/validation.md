## 如何复核

```bash
python3 -B -m unittest discover -s tests -v
python3 skills/sherry-douyin-review/scripts/prepare_video.py 测试素材/样例_泳后护发.mp4 --scenes
```

本地回归共 10 项，覆盖移动目录重复安装、非正／非有限／过密间隔、分数秒帧路径、参数错误、缺失显式字幕、检测失败、旧帧误用和标准样例。ffmpeg 缺失时部分测试会跳过；有跳过不等于完整通过。

自带 SRT 的标准样例：12 秒、540×960、30 fps，18 张有效帧、4 条字幕、3 个镜头，切点 4.0 与 8.0 秒。源视频 SHA256：`4ad71c4340471289fb51415bd1729d97934b847f3f038b5dfd8a0b00b11ad028`。

## 规则场景

| 场景 | 应有行为 |
|---|---|
| 视觉项通过，必要口播证据不可用 | 待补证据，不给通过 |
| 缺口播证据，同时确定必拍画面缺失 | 不通过，同时保留无法审核项 |
| 7 个维度有分、1 个 N/A | 正式总评暂缺；可列有标注的已评均分 |
| 8 个维度全部 N/A | 不计算均分，不选最弱维度 |
| 只缺不适用项 | 不影响适用项的正常判定 |
| JSON 的 scenes/srt 为 null，目录仍有旧文件 | 不读取旧统计、字幕或未列入 mapping 的帧 |
| 30 条预算，2×2 每格 7 条 | 28 条内容＋2 条余量，可行；不是统计功效证明 |
| 30 或 40 条，要求 3×2 每格 7 条 | 不可行；提议改范围或 A/B，不能静默删方向 |

这些是规则消费场景，不代表已经在大量真人视频中测出了稳定评分或业务收益。
